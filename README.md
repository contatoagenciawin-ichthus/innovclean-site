# InnovClean Services

Modern website for InnovClean Services Ltd, a family-owned commercial cleaning company serving London and the United Kingdom.

## Stack

- Next.js
- TypeScript
- App Router
- Vercel

## Content policy

This repository contains only clean, newly authored application code and curated public-facing content. Legacy WordPress/PHP files, database dumps, credentials, and compromised backup files must never be committed here.

## Language

Primary and current website language: English (UK).

## Development

```bash
npm install
npm run dev
```

Production target: Vercel.
